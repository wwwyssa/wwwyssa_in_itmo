## Линейная регрессия

Из корня проекта:

```bash
python -m pip install -r lab3/requirements.txt
python lab3/linear_regression.py
```

Из папки `lab3` можно запустить `python linear_regression.py`. Путь к CSV
определяется относительно скрипта, поэтому текущая папка не влияет на загрузку.

Скрипт использует только NumPy, Pandas и стандартную библиотеку Python:

1. Выделяет цель `median_house_value` и остальные 8 числовых признаков.
2. Делит строки на train/test в отношении 80/20 с фиксированным seed=67.
3. Заполняет числовые пропуски медианами train и стандартизует признаки:
   `(x - mean_train) / std_train`, где `std_train` рассчитано с `ddof=0`.
   Те же параметры применяются к test. Категориальных столбцов в исходном CSV
   нет, кодирование не требуется. Цель не стандартизуется; строки без цели
   исключаются перед разделением. Полностью пустые и постоянные признаки
   в train вызывают понятную ошибку.
4. Обучает три модели с заранее заданными наборами признаков:
   - `income`: только `median_income`;
   - `income_location_age`: `median_income`, `longitude`, `latitude`, `housing_median_age`;
   - `all_features`: все 8 исходных признаков.
5. Для каждой модели строит прогнозы и рассчитывает SSE, MSE, RMSE и R² для train
   и test по формулам. Все модели используют одинаковые строки train/test.
6. Оценивает зависимость каждой модели от признаков: поочерёдно перемешивает
   каждый столбец test 5 раз и измеряет среднее падение R² без переобучения.
   При связанных признаках такая оценка требует осторожной интерпретации.
7. Сравнивает R² test, эффект добавления групп признаков и формирует выводы
   в `report.txt` по фактическим результатам текущего запуска.

МНК минимизирует `SSE = sum((y - X @ b) ** 2)`. Из нулевого градиента получаем
`(X.T @ X) @ b = X.T @ y`; система решается собственной реализацией метода
Гаусса с выбором главного элемента из `Gauss.py` (класс `Gauss`, метод `solve`).
Готовые модели, решатели из `numpy.linalg`
и готовые метрики не используются. При линейной зависимости столбцов решатель
сообщает об ошибке. Нормальные уравнения чувствительны к плохой обусловленности;
для этой учебной реализации признаки предварительно стандартизуются.

Результаты появляются в `lab3/regression_results`:

- `model_comparison.csv` — наборы признаков, R² train/test, их разность и RMSE test.
- `report.txt` — сравнение трёх моделей и выводы о наборах и роли признаков.
- `feature_importance.csv` — среднее падение R² test при перемешивании каждого
  признака и стандартное отклонение по пяти повторам (это не доверительный интервал).
- `coefficients.csv` — свободный член и коэффициенты каждой модели для
  стандартизованных признаков, а также их пересчёт в исходные единицы.
- `metrics.csv` — метрики трёх моделей на train и test (6 строк).
- `preprocessing.csv` — медианы, средние и масштабы признаков, рассчитанные на train.
- `train_predictions.csv`, `test_predictions.csv` — исходный индекс строки CSV
  (с нуля, без заголовка), фактическое и предсказанное значения для каждой модели.
  Столбец `model` связывает прогнозы, коэффициенты и метрики с нужной моделью.

Для коэффициентов в исходных единицах прогноз вычисляется как
`intercept + sum(coefficient_j * x_j)` после заполнения пропусков.
Скрипт не использует Matplotlib; визуализация статистики остаётся в отдельном файле.
